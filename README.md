# Traffic Based Route Guidance System (TBRGS)

This repository contains a comprehensively integrated Python search engine and Machine Learning (ML) pipeline built to solve the Route Finding Problem under dynamic traffic conditions. It evaluates a 2D spatial graph to find the Top-K optimal paths from a specified origin node to a destination node, factoring in estimated travel times generated by historical traffic flow data.

This project was developed for Assignment 2B of COS30019 (Introduction to Artificial Intelligence) and demonstrates advanced informed graph traversal combined with predictive sequence modeling.

## Core Features

- **K-Shortest Paths Engine:** Extends standard pathfinding using Yen's Algorithm to reliably discover the top 5 most optimal travel routes between points simultaneously, dynamically routing around overlapping bottlenecks.
- **Machine Learning Flow Prediction:** Traffic congestion is dynamically predicted using one of three integrated forecasting models trained on historical SCATS data:
  - **LSTM** (Long Short-Term Memory Neural Network)
  - **GRU** (Gated Recurrent Unit Neural Network)
  - **Random Forest Regressor** (Ensemble Decision Trees)
- **Dynamic Graphical User Interface (GUI):** A local desktop application allowing interactive configuration of Origin/Destination tracking, time-index manipulation, and ML model toggling.

## Setup & Requirements

Because this pipeline integrates TensorFlow and Scikit-Learn natively within the search environment, a specific Python 3.11 environment is heavily enforced.

### Environment Setup (Dung's Note)

To ensure compatibility with TensorFlow (which lacks full native Windows support on Python >= 3.12 without WSL), a separate Python 3.11 environment was installed via Winget. The project was then configured to run under Python 3.11 by registering it as a Jupyter kernel (ipykernel) and selecting it in the notebook. Since this environment was newly created, all required libraries had to be reinstalled specifically for Python 3.11 using pip, including pandas, scikit-learn, and tensorflow. This ensures that data processing, model training, and deep learning components (LSTM/GRU) can run correctly within a compatible and consistent environment.

```bash
# 1. Install Python 3.11
winget install -e --id Python.Python.3.11

# 2. Verify Python 3.11
py -3.11 --version

# 3. Install core dependencies for Python 3.11
py -3.11 -m pip install pandas scikit-learn tensorflow openpyxl xlrd ipykernel

# 4. Register Python 3.11 as a Jupyter kernel (If executing the notebook)
py -3.11 -m ipykernel install --user --name py311 --display-name "Python 3.11"

# 5. Install standard dependencies
py -3.11 -m pip install -r requirements.txt
```

## Usage

### 1. Graphical Dashboard (Recommended)
You can launch the complete user interface natively to interact with the Top-K routing predictions without using the command line.

```bash
py -3.11 gui.py
```

### 2. Command Line Operations
The standard terminal execution is identically retained for legacy debugging, executing only the primary (best) route instead of the Top-K subset.

```bash
py -3.11 search.py PathFinder-test.txt as
```

### 3. Model Re-Training
To view the data-science pipeline, extract new SCATS data sequences, or evaluate the neural schemas side-by-side, open `notebook.ipynb` and trigger "Run All". The notebook will automatically re-export the trained models (`.h5` and `.pkl`) back into the root directory for the GUI to consume.
